# Clanboard

A family organiser for a wall screen and everyone's phones and computers:
shared calendar, chores as quests with rewards, lists and meals, and household projects.

These are **test builds**. This page only has the finished apps, not the source code.

## Install

**Linux** (Raspberry Pi OS 64-bit, Ubuntu, Debian and other 64-bit Linux). Open a Terminal and run:

```
curl -fsSL https://github.com/itsmylife10173/clanboard-releases/releases/latest/download/install.sh | bash
```

Run the same line again to update. It installs for your user only (no password needed), adds Clanboard to the app menu and opens it.
To remove it: `curl -fsSL https://github.com/itsmylife10173/clanboard-releases/releases/latest/download/install.sh | bash -s -- --uninstall`

**Windows:** open [Releases](https://github.com/itsmylife10173/clanboard-releases/releases/latest), download `clanboard-windows-x64.zip`, unzip it and run `clanboard.exe`.
If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

**Android:** on the phone or tablet, open [Releases](https://github.com/itsmylife10173/clanboard-releases/releases/latest), download `clanboard-android.apk` and open it. Allow installing from your browser if asked.

## Using it on several devices

Devices on the same Wi-Fi share one family. On a device that has the family, open **Settings**, then **Add a device**.
On the new device, tap **Join a family** and scan the code (phones) or paste it (computers).
