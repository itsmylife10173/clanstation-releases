# ClanStation

The free family organizer for a wall screen and everyone's phones and computers:
a shared family calendar, chores as quests with rewards, screen time, meals and recipes, lists and household projects.
No account, no ads.

**Website, screenshots and install steps: [clanstation.com](https://clanstation.com)**
· [What's new](https://clanstation.com/whats-new)
· [Try it in your browser](https://clanstation.com/demo/)

This page only has the finished apps, not the source code.

## Install

**Windows:** download [`clanstation-windows-x64.zip`](https://github.com/itsmylife10173/clanstation-releases/releases/latest/download/clanstation-windows-x64.zip), unzip it and run `clanstation.exe`.
If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

**Android:** on the phone or tablet, download [`clanstation-android.apk`](https://github.com/itsmylife10173/clanstation-releases/releases/latest/download/clanstation-android.apk) and open it. Allow installing from your browser if asked.

**Linux** (Raspberry Pi OS 64-bit, Ubuntu, Debian and other 64-bit Linux). Open a Terminal and run:

```
curl -fsSL https://clanstation.com/install | bash
```

Run the same line again to update. It installs for your user only (no password needed), adds ClanStation to the app menu and opens it.
To remove it: `curl -fsSL https://clanstation.com/install | bash -s -- --uninstall`

ClanStation updates itself after that.

## Using it on several devices

Devices share one family. On a device that has the family, open **Settings**, then **Sync and devices**, then **Add a device**.
On the new device, tap **Join a family** and scan the code (phones) or type it (computers).
